# Unauthorized Passenger UI Skin

Runtime UI for this skin is assembled from independent sprites and
`ui_skin.json`. The title screen no longer depends on the flattened PSD
preview.

Runtime sprites:

- `Sprites/dialogue_box.png`
- `Sprites/button_normal.png`
- `Sprites/button_hover.png`
- `Sprites/button_pressed.png`
- `Sprites/title_logo.png`
- `Sprites/title_logo_large.png`

The editable PSD source and slicing manifest are archived outside Unity's
`Assets` folder:

```text
ArtSource_Archive/UI/unauthorized_passenger_psd/
```
